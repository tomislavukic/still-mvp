Privacy

Still? is designed to work without an account. Return checks, recent checks, language and appearance preferences are stored in your browser. Receipt images used by the current on-device scanning feature are not intentionally uploaded to a Still? server.

Data minimisation

Do not enter sensitive personal information into the optional item field. Shared result links can contain the purchase details you choose to include, so review them before sharing.

Analytics

If privacy-preserving traffic analytics are enabled by the site operator, they should be used to understand aggregate site usage rather than build advertising profiles. This page will be updated if the data practices materially change.

Contact

Before commercial launch, the site operator should publish a working support/privacy contact address here.
